# Clothing Brand Financial & Production Operating System (v1.0.0)

> Template spreadsheet komprehensif untuk pemilik clothing brand, konveksi, dan fashion startup untuk mengelola HPP, penetapan margin retail/reseller, simulasi batch produksi, hingga analisis titik impas (BEP).

---

## 📦 Isi Paket Produk
File utama: `kalkulator-clothing.xlsx` (Microsoft Excel / Google Sheets kompatibel).

Workbook ini terdiri dari **5 Sheet Terintegrasi**:

1. **`Instructions` (SOP & Panduan Penggunaan)**
   - Standar Operasional Prosedur (SOP) 5 langkah penentuan harga.
   - Glosarium istilah finansial (HPP, Gross Margin, BEP Unit & Rupiah, ROI).
   - Panduan kode warna sel (Kuning = Input, Putih = Rumus Otomatis, Hijau = Output Kunci).

2. **`Dashboard` (Executive Summary & Visual KPI)**
   - 6 Kartu Metrik Utama: Total SKU, Rata-rata HPP, Rata-rata Margin Retail %, Total Modal Investasi, Proyeksi Omzet, dan Proyeksi Laba Bersih.
   - Tabel Perbandingan Profitabilitas Produk aktif.
   - **Stress Test Skenario Penjualan**: Proyeksi omzet, profit, dan ROI jika batch terjual 100% (Optimis), 75% (Moderat), 50% (Titik Impas), atau 30% (Skenario Buruk).

3. **`HPP_Calculator` (Kalkulator Detail Multi-Kategori)**
   - Dilengkapi 5 template produk fashion rilisan umum:
     - *Boxy Heavyweight T-Shirt* (Cotton Combed 16s 240 gsm)
     - *Classic Regular T-Shirt* (Cotton Combed 24s 180 gsm)
     - *Pullover Heavy Hoodie* (Cotton Fleece 330 gsm)
     - *Worker Utility Overshirt* (Baby Canvas Twill)
     - *Tactical Cargo Pants* (Cotton Ripstop)
   - Kolom kalkulasi akurat: Biaya kain/kg, konsumsi pola, ongkos jahit garment, sablon/bordir, label woven leher, hangtag, kemasan ziplock frosted, polymailer pengiriman, serta alokasi QC cadangan.
   - Kalkulasi otomatis target retail, laba kotor per pcs, persentase margin real, dan harga diskon reseller/grosir (markup 35%).

4. **`Batch_Planner` (Simulasi Produksi & Analisis BEP)**
   - Bagian 1: Alokasi volume rilis per SKU (total batch 330 pcs).
   - Bagian 2: Alokasi Biaya Tetap (Fixed Costs) peluncuran: sample pola, sewa studio & model foto katalog, iklan berbayar (Meta/TikTok Ads), influencer seeding, dan dana darurat packing.
   - Bagian 3: Formula otomatis Titik Impas (BEP) dalam satuan Helai (Unit) dan Nilai Omzet Rupiah, serta persentase ROI investasi.

5. **`Vendor_Database` (Katalog Vendor & Mitra Produksi)**
   - Template pencatatan mitra: Toko kain, konveksi jahit, studio sablon screenprint, produsen woven label, dan kemasan ziplock.
   - Kolom kontak WhatsApp, lokasi, MOQ (Minimum Order Quantity), estimasi waktu pengerjaan (lead time), dan catatan kualitas.

---

## 🚀 Cara Menggunakan
1. Buka file `kalkulator-clothing.xlsx` menggunakan **Microsoft Excel** atau upload ke **Google Sheets**.
2. Masukkan angka riil biaya produksi Anda hanya pada **sel berwarna kuning muda** (`#FEF9C3`).
3. Jangan mengubah sel berlatar belakang putih, abu-abu, atau hijau karena berisi formula dinamis.
4. Periksa sheet `Dashboard` untuk membaca analisis kelayakan finansial koleksi Anda sebelum memesan bahan ke vendor.
